# Talk2APK v0.5.4

## Changes
- Added project renaming from the project selector (pencil button) and Manage Projects. Renaming preserves the local project directory and its source files.
- Added animated progress feedback while AI work, publishing, and build tracking are in progress.
- Added floating chat navigation controls: up arrow scrolls to the first message; down arrow scrolls to the latest message. New messages automatically scroll into view.

## Update
Replace the contents of your GitHub repository with the contents of this folder, preserving the repository root layout, then commit and push. Check that the Actions run is for the new commit.
